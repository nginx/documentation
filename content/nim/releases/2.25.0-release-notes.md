November 18, 2026

NGINX Instance Manager 2.25.0 release notes

## Upgrade Paths {#2-25-0-upgrade-paths}

NGINX Instance Manager 2.25.0 supports upgrades from these previous versions:

- 2.22.0 - 2.24.1

If your NGINX Instance Manager version is older, you may need to upgrade to an intermediate version before upgrading to the target version.

## What's new {#2-25-0-whats-new}

This release includes the following updates:

- {{% icon-feature %}} **Track F5 WAF for NGINX security policy versions with sequential numbers and comments**<a name="2-25-0-whats-new-Track-F5-WAF-for-NGINX-security-policy-versions-with-sequential-numbers-and-comments-47851"></a>

   Security policy versions now display sequential labels, such as v1, v2, and v3, instead of timestamps. These labels make versions easier to identify, compare, and track across deployments. You can add or edit version comments through the web interface or REST API without creating a new version. Creation and deployment dates remain available separately. User-created policies with more than 100 versions display a memory-usage warning.

   See [Update the comment on a security policy version]({{< ref "/nim/waf-integration/policies-and-logs/policies/update-policy-version-comment.md" >}}) to get started.

- {{% icon-feature %}} **Configure gRPC Protection in F5 WAF for NGINX security policies**<a name="2-25-0-whats-new-Configure-gRPC-Protection-in-F5-WAF-for-NGINX-security-policies-48767"></a>

   Use gRPC Protection to configure how your policy inspects gRPC requests. Use gRPC Error Response to configure the response your policy returns to clients when it blocks a gRPC request.

   These settings are available under API Protection in the security policy wizard. gRPC violation actions and the error response apply to the whole policy. You configure protection settings and Interface Definition Language (IDL) files separately for each gRPC profile.

   See [gRPC Protection settings]({{< ref "/nim/waf-integration/policies-and-logs/policies/grpc-protection-settings.md" >}}) to get started.
