Before you can deploy F5 NGINXaaS for AWS, you need to complete some prerequisites.

## Subscribe to the NGINXaaS for AWS offering

If it's your first time using NGINXaaS for AWS, you need to find the offering in the AWS Marketplace and subscribe to it:

### Get the offering in the AWS Marketplace

1. Find the [NGINXaaS for AWS product listing in the AWS Marketplace](https://aws.amazon.com/marketplace/).
1. Log in with your AWS account.
1. Select **Subscribe** to subscribe to the NGINXaaS for AWS offering.
1. Currently the **Enterprise** plan is the only plan supported. This option is selected automatically.
1. Select the AWS account you want to use for this deployment.
1. Agree to the terms of service and privacy policy.
1. Select **Subscribe** and a message will confirm that your subscription request has been sent to F5, Inc.
   - Once F5 NGINXaaS for AWS receives your subscription request, it will be automatically approved.
   - This approval process may take several seconds to complete in the background.
1. Next, select **Set up your account** to proceed.
   - In the **Welcome to F5 NGINXaaS for AWS** window, select **Close Window** to return to the AWS Marketplace.
1. You can now log into the NGINXaaS for AWS console by selecting **Manage subscriptions** from the AWS Marketplace.
